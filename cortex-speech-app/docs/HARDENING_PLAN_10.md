## Remaining RED policy gates (need Windows to fix safely)

### 1. `test_model_provenance_policy.py` -- OmniASR archive download must do network IO with SHA preflight+verify
- **Assertion:** for each pinned archive label, `models.rs` must, in order, call the SHA preflight (`ensure_pinned_sha256`), then make an explicit `ureq::get` network request, then `verify_sha256` on the downloaded `.tar.bz2`.
- **Current reality:** `models.rs` has `ensure_pinned_sha256`, `verify_sha256`, and the pinned `OMNIASR_CTC_300M_ARCHIVE_URL`/`OMNIASR_CTC_1B_ARCHIVE_URL`, but the OmniASR archive code path does not reach a `ureq::get` after the preflight anchor (the Silero VAD path does). So the test fails on "must make explicit network requests".
- **Fix:** implement the OmniASR archive download to mirror the Silero VAD path -- `ensure_pinned_sha256(label, sha)` -> `ureq::get(url)...` -> write `.tar.bz2` -> `verify_sha256(path, sha)` -> extract. Keep the empty-SHA refusal (`Missing pinned SHA256 for {label}; refusing to download unverifiable artifact`).
- **Why not done here:** it is real backend code that must compile and ideally be exercised against a pinned SHA; doing it blind without `cargo` risks shipping a green-looking-but-broken download. **needs Windows.**

### 2. `test_rust_runtime_panic_policy.py` -- panic-prone pattern in `jury/mod.rs`
- **Assertion:** no un-allowlisted panic-prone pattern returns; it flagged `src-tauri/src/jury/mod.rs: .unwrap_or_default()`.
- **Current reality:** the only `unwrap_or_default()` in that file is in a test at ~line 642: `db.get_segment_by_id("s-dial").unwrap().unwrap().verdict.unwrap_or_default()...` -- the real panic risk is the `.unwrap().unwrap()` chain, not `unwrap_or_default()`.
- **Fix:** in that test, replace the `.unwrap().unwrap()` chain with `expect(...)` carrying a message, or restructure so the policy's allowlist matches; re-run the policy and `cargo test` to confirm the test still asserts the same behavior.
- **Why not done here:** the 77KB policy uses a per-file allowlist; the correct change must be checked against it AND compiled. **needs Windows.**
