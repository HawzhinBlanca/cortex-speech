## 2. The integrated engine architecture (local 7B + Gemini 2.5 Pro + Scribe v2 fusion)

**Keep IRT as the fusion engine — do NOT rebuild it.** The fix is feeding it diverse inputs and calibrating its output. The architecture is a **3-tier local-first cascade** that spends cloud money only on the hard minority:

- **Tier 0 (free, every segment):** Run local fine-tuned OmniASR-7B + OmniASR-CTC-1B (cheap CTC diversity + alignment scores). Build the IRT confusion-network consensus + cross-engine agreement. Apply LOOP-0 firing if enabled and `firing_error_delta ≤ 0` proven.
- **Conformal gate (the routing decision):** Compute the nonconformity vector `[1 − irt_confidence, cross_engine_agreement, ctc_score, snr]` against the conformal threshold. If calibrated-confident AND audio not poor-quality (SNR≥5, clipping≤0.1) → **AUTO-ACCEPT, zero cloud cost.** Else escalate. **This gate is only trustworthy once Tier 0's confidences are REAL posteriors and ECE is measured (§6) — until then it routes on partly-heuristic scores and must NOT be used to claim a calibrated auto-accept rate.**
- **Tier 1 (Scribe v2 — cost [unverified], pricing not published in researched sources):** On low confidence, add ElevenLabs Scribe v2 as a diverse acoustic voter. **Caveat: Scribe's ckb quality is [unverified] and ElevenLabs' own tier is "Moderate >25-50% WER"** — it is a *diversity voter*, not a trusted anchor; weight it by its *learned* IRT ability on the curator's gold set, not by vendor marketing. Prime Scribe's keyterm prompting with the curator's Sorani named entities.
- **Tier 2 (Gemini 2.5 Pro, expensive, audio-grounded — ckb quality [unverified]):** Only when 7B+Scribe still disagree on a content word → audio-grounded GER over the *full confusion set + the audio clip*. Self-consistency N=3, order-rotated. **Gemini breaks ties; it NEVER overwrites a high-agreement IRT consensus** (GER hallucination guard).

**Routing/confidence rules (decisive):**
- Replace the constant confidences with the conformal-calibrated nonconformity vector. **Until REAL CTC posteriors replace any hard-coded confidence, tag `confidence_source = Heuristic` and refuse to publish any calibration claim** — the refusal is part of the anti-self-deception gate.
- Cloud voting is **opt-in** (`jury_cloud_opt_in`), **additive/best-effort** (warn+continue on failure, mirroring today's `populate_hypotheses` contract), and **cached by blake3 audio hash** so a re-run never re-pays and an outage still has yesterday's vote.
- **Fail-safe:** on any cloud outage, IRT fuses fewer hypotheses → conformal confidence drops → *more* segments escalate to the human. **Never auto-accept on a lone surviving engine.** Lower confidence → more review, never silent acceptance.

**Integration seam (exact):** Generalize `pipeline.rs::populate_hypotheses` (line 1713) from the hard-coded 3-model block into a provider loop over an enabled-engines set; each provider returns `(model_id, transcript, confidence)` inserted via the existing `insert_hypothesis_checked` (line 92). IRT picks them up for free because it keys on `model_id`. Add a thin `scribe_api.rs` mirroring `gemini_api.rs` (`model_id = "elevenlabs-scribe-v2"`). Port `rover_fuse` (verified at `scripts/sorani_ensemble_asr.py:98`) into Rust as the 2-hypothesis fallback so the primary path never depends on the standalone Python script.

**Mandatory anti-rot guards (each maps to a named failure mode):**
- *confirmation bias* → Stream B uses cross-architecture consensus + independent audio-LLM, NEVER the 7B's own output alone. **Hard rule: a silver label requires agreement of at least two architecturally-independent engines (e.g. CTC-1B + Scribe-v2), never the 7B agreeing with itself or with a model the 7B's output was used to prompt.**
- *shared blind spot* → periodically human-audit a random silver sample; track silver→overturn rate; if it rises, silver weight auto-decays toward 0.
- *error accumulation / model collapse* → cap ≤2 self-training rounds before a mandatory human-correction infusion; **a fine-tune round whose training data is >X% silver is blocked** (silver can never be the majority of any round's new data).
- *forgetting* → **non-negotiable replay buffer** (new-delta + frozen stratified prior-verified sample + CC0 Common Voice ckb general slice — NEVER AsoSoft into a shippable adapter if its license forbids redistribution; CC-BY-SA contaminates a permissive release — confirm each corpus license before mixing).

**Cadence — trigger on accumulated signal, not a timer:** count trigger (≥ ~300-500 new non-holdout corrections, tune) OR drift trigger (rising silver-overturn rate or gold-slice CER). Each trigger emits a reproducible training manifest (deltas + replay mix + content-hashed corpus + recipe, recorded in the `adapters` row).
