# Cortex Speech — Roadmap to a True 10/10

> Generated 2026-06-17 by a 14-agent research+synthesis workflow (6 SOTA sweeps, 3 repo audits, adversarial critique). Source of truth for the autonomous agent in [AGENT_CHARTER.md](../AGENT_CHARTER.md).

## North Star
A 10/10 Cortex is a fully-offline, git-versioned, signed, auto-updating desktop app whose every public claim is independently reproducible by a stranger AND legally + ethically redistributable: it ships a commit-pinned, network-sandbox-reproducible Central Kurdish CER/WER scorecard (FLEURS ckb_iq + AsoSoft, AsoSoft-normalized) that beats Whisper at MAPSSWE p<0.05 and approaches the Omnilingual teacher, computed by a self-contained ASR-on-gold runner with no caller-supplied text; whose gold references carry a measured inter-annotator-agreement ceiling and whose Disagreement Refinery is proven by a measured label-quality-lift number beating Cleanlab; whose published dataset/checkpoint artifacts carry per-segment source-license + attribution + consent provenance that passes a CC-BY/CC-BY-SA/LDC compatibility audit; whose per-dialect (and per-gender/age where metadata exists) CER disparity stays within a published fairness budget; and whose every quality gate (fuzz, mutation, eval-regression, fairness, a11y, supply-chain, egress, license/version-sync) is enforced in CI with SLSA L2 provenance — i.e. accuracy, ethics, and verifiability are all gated, not asserted.

## Positioning (resolves the offline-vs-cloud contradiction)
Cortex is a fully-offline Central Kurdish speech transcription and dataset-curation engine for an at-risk, surveilled minority language: the ASR model, the tiered Disagreement Refinery jury (T0 conformal gate -> T1 text judge -> local T2 listener -> cross-family debate), and all calibration run 100% on-device by default with zero network egress (enforced by a runtime egress sandbox test, not a source grep); cloud models (Gemini) are an explicit, off-by-default, informed-consent opt-in gated behind a cross-border-biometric-transfer disclosure, and the published headline accuracy numbers are always the local-only numbers. The offline-vs-cloud contradiction is resolved by (a) making the headline benchmark the local-only number, (b) shipping a local T2 reference/listener using the already-running OmniASR CTC-1B as cross-checker so the full T0->debate cascade works offline, (c) demoting Gemini (default-false in settings.rs but currently load-bearing across jury/{debate,t2_listener,learning,mod}.rs) to a consent-gated opt-in, and (d) proving the whole posture with a runtime no-egress test in default config plus a consent-disclosure test on the opt-in path.

## Sequencing rationale
Three structural fixes drive the resequencing. (1) Compliance moved upstream: a new Wave 0 M0 (DATA_GOVERNANCE.md + per-corpus license/consent ledger + CC-BY/CC-BY-SA/LDC compatibility audit) is now a hard dependency of every publish/train/redistribute milestone (M4b, M9, M12, M13, M14, M15), inverting the V1 anti-pattern of deferring attribution to a Wave-3 NOTICE file — for an at-risk surveilled-minority language, unproven consent/redistribution rights make the scorecard non-verifiable-by-a-stranger regardless of CER. (2) Truth-before-publish: language='ckb' wiring (was buried in Wave-3 M14) is pulled into Wave 0 as the M2b spike BEFORE M4b pins any number, so the headline scorecard cannot shift later and break reproducibility; inter-annotator agreement (M3b, an orphaned V1 exit criterion) now precedes M4b so no CER is published against an unmeasured label-noise ceiling; M1 absorbs the MIT->Apache relicense + version/license-sync CI and the doc-honesty fixes so the public repo is never self-contradictory; and M4 is split into M4a (acquire datasets + stand up the absent Whisper-large-v3 baseline — a real infra task that can run parallel to the refinery) and M4b (publish under an enforced network sandbox). (3) De-risk the solo+AI critical path: cargo-mutants and the long eval move from PR-blocking to nightly-required so PRs don't stall; macOS notarization is demoted to an explicitly-flagged stretch leg (ci.yml has no macOS runner and the dev is on Windows) while Windows signing ships first and unblocks the updater and winget; the LoRA SOTA fine-tune (M13) is decoupled so M14/M15/M16 no longer chain off it and an underperforming fine-tune leaves the honest stock-CTC scorecard shippable; M8 is split into read-only panels (M8a) vs the backend-touching Autonomy Dial (M8b); a named reference machine + GPU-budget decision is required in Wave 0 feeding M13/M16; and two new dimensions (Ethics & Data Governance, Sustainability & Bus-factor) make previously-invisible blockers — consent, license compatibility, telemetry governance, SECURITY.md/CODEOWNERS that OpenSSF Scorecard actually grades — first-class and gated rather than assumed.
