**enforced**, not asserted. A *literal* 9.5 average needs two unlocks I won't hide:
1. **A second PR reviewer** — OpenSSF Code-Review + Branch-Protection (both High-weight) cap a solo repo
   ~8.x, holding Engineering-rigor and Sustainability down **[external]**.
2. **Northern Kurdish (kmr) + per-dialect CER** — Language-breadth can't pass ~8 on Sorani alone.

Without those, the honest ceiling is ~9.0–9.2 — still historic for this niche. macOS notarization is the one
allowed stretch; Flathub now **bans AI-assisted submissions** so it must be human-authored or dropped **[external]**.

## 3. The proof protocol (so nothing fakes "done" — including me)
Every milestone PR returns its **PROOF** artifact. Rules: (1) no metric without a reproducer (cmd + dataset SHA
+ model SHA); (2) `#[ignore]` passing ≠ done — gates must run in CI, shown RED-then-GREEN; (3) Rust proofs run
on Windows (real `cargo` output); (4) CI proofs are run URLs; (5) user-observable or it isn't done; (6) **audit
from the git root `CORTEX/`, never a subdir** — this whole correction came from breaking that rule; (7) a
milestone flips its gate in `scripts/verify_10.py` only when the real check passes.
