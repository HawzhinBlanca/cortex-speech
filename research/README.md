# research/

One-off / exploratory scripts from earlier dataset and pipeline work. **None are part of the
app build, tests, or CI** — the shipped app lives in `cortex-speech-app/` and its maintained
tooling in `cortex-speech-app/scripts/`.

Kept for reference and reproducibility. They were moved here (from the repo root) purely to
declutter; git history is preserved (`git log --follow <file>`). If you run one, run it **from
the repository root** — several read paths relative to the current working directory.
